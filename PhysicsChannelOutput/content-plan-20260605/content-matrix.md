# Контент-матрица на 14 постов

Канал: физика/математика для школьников.  
Цель: чередовать полезные сохранёнки, мемные хуки, мини-разборы и спокойные планеры, чтобы лента не выглядела однотипно.

## Правила выпуска

- Один главный смысл на карточку.
- Текст, формулы, графики и числа — только детерминированным слоем.
- ImageGen — для персонажа, сцены, бумаги, фактуры, стикеров, настроения.
- Примеры пользователя — планка качества, не шаблоны.
- Если стиль начинает повторяться, следующий пост уводить в другой визуальный режим.
