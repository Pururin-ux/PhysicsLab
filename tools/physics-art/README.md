# Physics Art — процедурные текстуры (C++)

`lab_textures.cpp` — автономный генератор фоновых текстур для web-оболочки.
Пишет PNG напрямую (собственный энкодер: CRC32/Adler32 + deflate stored),
поэтому для сборки нужны только `g++` и стандартная библиотека — без npm-
зависимостей и без внешних утилит.

## Зачем C++

Текстуры должны быть крошечными (суммарно < 20 КБ), бесшовными и
детерминированными от запуска к запуску. Такой генератор — чистая вычислительная
задача: циклы по пикселям и битовая арифметика, без DOM и без сторонних
форматов. Web-стек для этого не нужен, а пересборка занимает секунду.

## Сборка и регенерация

```bash
g++ -std=c++17 -O2 -Wall -Wextra -o /tmp/lab-textures lab_textures.cpp
/tmp/lab-textures ../../apps/web/public/art/textures
```

Выходные файлы (gray+alpha PNG, бесшовные тайлы):

| Файл | Назначение |
| --- | --- |
| `lab-grid.png` | лабораторная сетка 56×56: тонкая линия + узел-точка |
| `lab-noise.png` | мягкое зерно 64×64 (две октавы value-noise) |

Сгенерированные PNG коммитятся в репозиторий: рантайм читает только их.
Исходник нужен лишь при изменении дизайна текстур.

## Как слой используется

`apps/web/styles/globals.css`, селектор `.app-shell`: обе плитки повторяются
через `background-repeat` поверх радиальных световых пятен. В светлой теме
сетка приглушается автоматически через токены `color-mix`, отдельных
переопределений не требуется.
