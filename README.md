# PhysicsLab

Тренажёр по физике для подготовки к ЦЭ/ЦТ в Беларуси. Основная идея — короткие тренировки по 10 задач, разбор типичных ошибок и понятный прогресс без выдуманных процентов готовности.

## Структура

- `apps/web` — основное приложение на Next.js 15, React 19 и Tailwind v4
- `apps/web/lib/server/task-generator` — генератор задач
- `legacy/` — старые прототипы, оставленные только для истории проекта

## Установка

```bash
npm ci
npm ci --prefix apps/web
```

## Основные команды

```bash
npm run dev
npm run check
npm test
npm run test:physics
npm run test:e2e
npm run build
npm run smoke
```

## Что уже есть

- каталог типов задач;
- тематические и смешанные тренировки;
- задачи с выбором ответа и числовым вводом;
- разбор ошибок и контекстная справка;
- формулы и несколько эталонных решений;
- сохранение прогресса и восстановление незавершённой тренировки;
- автоматические проверки физики, интерфейса и основных пользовательских сценариев.

Проект пока не является полной имитацией варианта ЦЭ/ЦТ: покрыты не все разделы и не все типы заданий. Это рабочий тренажёр, который постепенно расширяется.

## Технические заметки

Playwright по умолчанию поднимает свой сервер на `:3000`. Если порт уже занят, сначала остановите запущенный dev-сервер или явно включите переиспользование существующего сервера.

Страницы `/dev/*` используются только во время разработки и не входят в production-сборку.
