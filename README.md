# PhysicsLab

Тренажёр по физике для подготовки к ЦЭ/ЦТ в Беларуси. Тренировка строится вокруг коротких сессий по 10 задач, разбора ошибок и сохранения прогресса.

## Структура

- `apps/web` — приложение на Next.js 15, React 19 и Tailwind v4
- `apps/web/lib/server/task-generator` — генератор задач
- `docs` — справочные материалы по содержанию и эксплуатации проекта
- `tests` внутри приложения — проверки физики и пользовательских сценариев

## Запуск

```bash
npm ci
npm ci --prefix apps/web
npm run dev
```

## Проверки

```bash
npm run check
npm test
npm run test:physics
npm run test:e2e
npm run build
npm run smoke
```

## Что реализовано

- тематические и смешанные тренировки;
- задачи с выбором ответа и числовым вводом;
- разбор ошибок и контекстная справка;
- формулы и эталонные решения;
- сохранение прогресса и восстановление незавершённой тренировки;
- автоматические проверки физики, интерфейса и основных пользовательских сценариев.

Проект пока не покрывает все разделы и типы заданий ЦЭ/ЦТ. Это рабочий тренажёр, который постепенно расширяется.
