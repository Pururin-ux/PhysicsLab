# PhysicsLab

Тренажёр по физике для подготовки к ЦЭ/ЦТ в Беларуси. Основная идея — короткие тренировки по 10 задач, разбор типичных ошибок и понятный прогресс без выдуманных процентов готовности.

## Структура

- `apps/web` — основное приложение на Next.js 15, React 19 и Tailwind v4
- `apps/web/lib/server/task-generator` — генератор задач
- `legacy/` — старые прототипы, оставленные только для истории проекта

## Установка

```bash
npm ci
npm ci --prefix apps/web
```


## Что уже есть

- семь разделов: Сегодня, Учиться, Задачи, Диагностика, Ошибки, Формулы, Прогресс;
- уроки по пяти темам (`/topics/[topic]`): зачем тема, что спрашивают, опорные идеи с формулами и ловушками, порядок решения, типы задач темы;
- дашборд «Сегодня»: план на день, серия дней, незавершённая тренировка, слабые места и результат диагностики;
- каталог типов задач с поиском, фильтром по теме и картой покрытия программы;
- диагностика (`/exam`): 10 задач по пяти темам вперемешку, карта покрытия до старта, восстановление незавершённой попытки;
- тематические и смешанные тренировки, задачи с выбором ответа и числовым вводом;
- разбор ошибок, контекстная справка и план повторения;
- справочник формул с обозначениями, условиями применения и фильтром по теме;
- прогресс: XP, точность, слабые места, история диагностик, экспорт и импорт данных;
- автоматические проверки физики, интерфейса, доступности и основных пользовательских сценариев.

Границы покрытия и методика описаны на странице «О проекте» (`/about`).

Проект пока не является полной имитацией варианта ЦЭ/ЦТ: покрыты не все разделы и не все типы заданий. Это рабочий тренажёр, который постепенно расширяется.

## Технические заметки

Playwright по умолчанию поднимает свой сервер на `:3000`. Если порт уже занят, сначала остановите запущенный dev-сервер или явно включите переиспользование существующего сервера.

Страницы `/dev/*` используются только во время разработки и не входят в production-сборку.
