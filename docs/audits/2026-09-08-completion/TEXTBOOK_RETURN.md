# Возвращение к самопроверкам учебника

2026-09-08. В оглавлении /learn видны последние сохранённые ответы:
не пройдена, выбран без проверки, неверный, верный, вопрос обновлён,
запись недоступна. Верный ответ не называется освоением главы.

Фильтр возвращения включает неверные, незавершённые и обновлённые вопросы;
ссылки ведут к #self-check. Нет расписания интервального повторения или
оценки долговременного знания: эти функции ещё предстоит реализовать.

Чтение использует общие кодеки черновиков и не меняет хранилище. Недоступные
и будущие записи не выдаются за непройденные и не удаляются. Изменения
обновляются при возвращении на страницу, focus, storage и pageshow.
Ключ версии вопроса общий с самим компонентом TextbookCheck.

TypeScript прошёл. Четыре браузерных сценария на desktop/mobile-390
проверяют ошибку → фильтр → исправление → обновлённое оглавление и
сохранение повреждённой записи. Мобильный интерфейс осмотрен в браузере.
