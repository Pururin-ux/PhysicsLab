# Плотность: связный учебный маршрут

2026-09-08. Продолжение после реализации /learn/density.

Браузер: существующий урок /practice/density-lesson восстановил прежний
этап. Наблюдение, формула, разбор, частичная подсказка, самостоятельная
задача и перенос пройдены до итогового экрана. Поля ответов на новых этапах
пустые, правильный ответ предыдущего этапа не открывает следующий.

Исправлены обнаруженные проблемы:

- В самостоятельной задаче готовый способ «раздели массу на объём»
  заменён нейтральной инструкцией; после ошибки помощь остаётся доступна.
- Для сравнения плотностей уточнены однородность, отсутствие полостей,
  одинаковая температура и состояние вещества.
- Название области соответствует уровню VII класса.
- Общий итог TopicPrimer больше не подставляет пример про ускорение
  в плотность, электричество и оптику. Вопрос просит назвать связь и условия.
- После успешного сохранения есть ссылка в тетрадь и явное различие
  между личной записью и автоматической оценкой объяснения.

Проверка: npm run check успешно. density-journey.spec.ts проходит весь
маршрут с чистого состояния: прогноз, наблюдение, разбор, неверный и верный
самостоятельные ответы, отдельный перенос, сохранение, перезагрузка и
видимая запись в тетради. Desktop 1440×960 и mobile-390.
Первый запуск остановлен после обнаружения неверной роли в селекторе
нового теста: прогноз использует кнопки с aria-pressed, а не radio.

Ограничение: этот маршрут не доказывает учебную эффективность с реальными
школьниками, полноту курса, а также прохождение всех задач семейства.
