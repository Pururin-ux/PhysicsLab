# Давление: самостоятельная тренировка

2026-09-08. Новый тип contact-pressure: общая сила, 2–4 одинаковые
опоры, площадь в см², результат в кПа. Условия явно задают равномерность
распределения и перпендикулярность силы. Варианты ошибок: одна опора,
неверные единицы, повторное деление силы на число опор.

Тип зарегистрирован в генераторе, каталоге, таксономии, графе понятий,
справочнике формул, помощи и подсказках ошибок. Группа mechanics/dynamics;
вводная глава остаётся VII класса. Глава ведёт к пяти новым задачам;
итог и страница типа возвращают к /learn/pressure.

Промежуточная площадь сохраняет точность: 15 см² = 0,0015 м². Общий
форматтер ответов с тремя знаками после запятой для неё не используется.
Конечный ответ в кПа при необходимости округляется до тысячных.

Проверки: 84 теста генератора/метаданных/помощи/графа/формул и отдельного
расчёта прошли. Обновлены явно перечисленные наборы с 35 до 36 семейств,
динамика — с 10 до 11. TypeScript прошёл.
pressure-family.spec.ts: desktop/mobile-390, ответы вычисляются из видимого
условия, первая ошибка, помощь правильной темы, итог 4/5 и переход в главу.

Браузерная проверка решения 75 Н / (2×20 см²) = 18,75 кПа выявила
несогласованное «Ты Учитывает…» из новых названий ошибок. Названия исправлены
на «учёл», «не перевёл», «разделил» под существующий шаблон обращения.

## Расширение: три искомые величины

Добавлены обратные задачи на полную силу F=pS и суммарную площадь S=F/p.
Исходные данные подбираются через точные давление и площадь; округление
промежуточного значения не меняет ответ обратной задачи. Общие подсказки
теперь предлагают сначала выразить искомую величину.

В браузере обнаружено повторение одного численного набора в соседних прямой
и обратной задачах. Для этого семейства каждый набор закреплён за одной
искомой величиной: готовый ответ не переносится из предыдущего условия.
Тест проверяет отсутствие повторов исходных наборов и покрытие всех трёх
единиц ответа. Пять задач в реальном маршруте также содержат все три цели.

После расширения: 54 теста генератора прошли; полный маршрут на desktop
и mobile-390 — 2/2. TypeScript проверен после добавления обратных задач.
Ручной осмотр мобильного состояния 390×844: условие задачи на силу и четыре
варианта ответа читаются, нижняя навигация не перекрывает ответы.

Граница: требуется перенос с другой геометрией и расширение всей темы
(жидкости, газы, закон Паскаля). Production-сборка после добавления типа
не запускалась. Эти проверки не доказывают готовность всей платформы.
