PhysicsLab is a learning platform with partial implemented coverage. Neither
this index nor the release objective authorizes resuming product work when the
current user request is limited to an audit or instructions.

`docs/archive/`, `legacy/`, snapshots and dated audits preserve history; they
do not override current contracts. Nova-named components and old artwork do
not establish a second approved companion. Check consumers before any cleanup.

`apps/game` and `PhysicsChannelKit` / `PhysicsChannelOutput` are separate work.
Design-sync and Sites/Vinext are optional tooling, not product authority.

Rendered inspection is evidence, not a ritual. Choose checks for a concrete
failure mode using `QUALITY.md`; the visual-verdict skill is opt-in.

Branch/PR relationships and installation limitations observed on 2026-09-12
are recorded in [the integrity audit](../audits/2026-09-12-repository-integrity.md).
That report is dated evidence, not a permanent default-branch decision.
