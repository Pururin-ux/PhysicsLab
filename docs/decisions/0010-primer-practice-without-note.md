# 0010 — Практика после урока без обязательной заметки

Status: `CANON`.

Scope: `apps/web`, итоговый экран уроков на общем `TopicPrimer`.

## Problem

После правильного переноса идеи ученик доходил до итога, но переход к
связанным задачам появлялся только после записи не короче 12 символов и
успешного сохранения в браузере. Личная запись становилась техническим
условием продолжения, хотя она не оценивает понимание темы.

## Decision

- Показывать переход к задачам на итоговом экране независимо от личной записи
  и доступности хранилища браузера.
- Сохранять существующие проверки ответов на предыдущих этапах. Переход не
  означает освоения темы и не меняет практический прогресс.
- Подтверждение сохранения и ссылку на тетрадь показывать только после
  успешного сохранения. Правила черновика и записи не менять.
- Решение относится к урокам `TopicPrimer`, а не задаёт порядок для всех тем.

## Focused verification

На итоговом экране без заметки доступен ровно один переход к задачам; после
сохранения та же ссылка остаётся одной, а тетрадь появляется отдельно.
Ошибка хранилища не скрывает задачи и не выдаёт запись за сохранённую.
