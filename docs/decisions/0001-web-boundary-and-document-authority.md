# 0001 — Web boundary and document authority

Status: `CANON`.

## Decision

`apps/web` and `apps/game` are separate products. `docs/current/` is the
operational source for the web trainer. Game work follows
`docs/game-preproduction/CONTEXT.md`. Archived documents preserve evidence but
do not impose requirements.

## Consequence

An agent must not import game requirements into the web trainer, or historical
web requirements into current work, without an explicit request.
