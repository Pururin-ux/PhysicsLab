## Единица доказанного покрытия

Для каждого умения: точный источник и раздел; понятное объяснение;
содержательная иллюстрация/модель; разобранный пример; новая самостоятельная
задача; обратная связь без преждевременного раскрытия ответа; повторение;
проверенный маршрут и сохранение. Только после этого умение отмечается
реализованным. Покрытие крупной темы требует всех её обязательных умений.

## Очередь разработки

1. Основа VII класса: измерения → объём → масса и плотность. Это устраняет
   пробел в предпосылках существующего урока плотности.
2. Завершение механики VII/IX: различать вводное изучение скорости VII
   и векторное описание IX; не маркировать одним классом всё семейство задач.
3. VIII: тепло, электрические цепи, свет с разными типами моделей.
4. X–XI: последовательно закрывать крупные разделы вместе с задачами.
5. Экзаменационная карта ведётся отдельно по проверенной спецификации РИКЗ.
